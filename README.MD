# ESP32P4_TOOL

## 功能
    电流表，电压表，逻辑分析仪，串口调试工具，蓝牙调试工具，WIFI调试工具，SPI调试工具，IIC调试工具，DSI调试工具，CSI调试工具,USB调试工具

## UI 菜单界面参数

### 屏幕配置
- **显示屏**: EK79007 MIPI DSI LCD
- **物理分辨率**: 480x800
- **屏幕旋转**: 90°
- **逻辑分辨率**: 800x480
- **触摸控制器**: GT911

### 菜单布局
- **风格**: 手机桌面风格，深色背景 (#1A1A2E)
- **顶部状态栏**: 高度 50px，显示 "ESP32P4 TOOL" 标题
- **网格布局**: 4 列 x 3 行，共 12 个槽位
- **图标尺寸**: 68x68 圆角矩形（圆角半径 16px），带阴影效果
- **图标字体**: Montserrat 20，名称字体: Montserrat 14
- **底部提示条**: 点击图标后弹出，2秒后自动隐藏
